# Enum Tests

Reads a Go type definition with `go:generate stringer` or
iota constants, emits exhaustiveness, stringer, boundary,
and round-trip tests.

## go:generate directive

```go
// Single enum type:
//go:generate testkit enum -o status_enum.gen_test.go Status

// Multiple enum types from the same package into one file
// (e.g., order.go defines Status, Priority, and Region):
//go:generate testkit enum -o status_enum.gen_test.go Status Priority Region
```

## Default output

`<type>_enum.gen_test.go`

## What is generated

Given an enum type `Status` with constants `StatusPending`,
`StatusConfirmed`, `StatusShipped`:

```go
// Code generated by testkit enum. DO NOT EDIT.

package order_test

import (
    "encoding/json"
    "fmt"
    "testing"

    "go.thesmos.sh/testkit"
    "example.com/myapp/order"
)

// allStatusValues lists every named Status constant.
// When a new constant is added, go generate updates this
// list — if the developer forgets, the test fails to compile.
var allStatusValues = []order.Status{
    order.StatusPending,
    order.StatusConfirmed,
    order.StatusShipped,
}

func TestStatus_Exhaustive(t *testing.T) {
    t.Parallel()

    // Verify every named constant appears in the test table.
    // This test fails to compile when a new constant is added
    // but the generated file is not regenerated.
    for _, k := range allStatusValues {
        t.Run(k.String(), func(t *testing.T) {
            // Existence in the table is the assertion.
            _ = k
        })
    }
}

func TestStatus_Stringer(t *testing.T) {
    t.Parallel()

    for _, k := range allStatusValues {
        t.Run(k.String(), func(t *testing.T) {
            s := k.String()
            // Named constants must produce a human-readable name,
            // not the fallback "Status(N)" format.
            testkit.False(t,
                len(s) > 7 && s[:7] == "Status(" && s[len(s)-1] == ')',
                fmt.Sprintf("Status(%d).String() = %q must not be fallback format", k, s))
        })
    }
}

func TestStatus_Boundary(t *testing.T) {
    t.Parallel()

    // Zero value must be "unspecified" or similar.
    zero := order.Status(0)
    testkit.True(t, zero.String() != "",
        "Status(0).String() must not be empty")

    // Max named + 1 must produce fallback format.
    beyondMax := order.Status(4) // one past StatusShipped
    s := beyondMax.String()
    testkit.True(t,
        len(s) > 7 && s[:7] == "Status(",
        fmt.Sprintf("Status(%d) beyond max must use fallback format, got %q", beyondMax, s))
}

func TestStatus_JSONRoundTrip(t *testing.T) {
    t.Parallel()

    // Only generated if Status implements json.Marshaler.
    for _, k := range allStatusValues {
        t.Run(k.String(), func(t *testing.T) {
            data, err := json.Marshal(k)
            testkit.NoError(t, err, "Marshal")
            var got order.Status
            err = json.Unmarshal(data, &got)
            testkit.NoError(t, err, "Unmarshal")
            testkit.Equal(t, got, k, "JSON round-trip")
        })
    }
}

func TestStatus_CodecRoundTrip(t *testing.T) {
    t.Parallel()

    // Only generated if Status has MarshalCodec/UnmarshalCodec.
    for _, k := range allStatusValues {
        t.Run(k.String(), func(t *testing.T) {
            data, err := k.MarshalCodec()
            testkit.NoError(t, err, "MarshalCodec")
            var got order.Status
            err = got.UnmarshalCodec(data)
            testkit.NoError(t, err, "UnmarshalCodec")
            testkit.Equal(t, got, k, "Codec round-trip")
        })
    }
}
```

## Enum detection

The generator finds enum types by:

1. Types with `//go:generate stringer` directives
2. `const` blocks where every value is of the same named
   type and uses `iota`
3. Types explicitly listed in `.testkit.yml` under `enums:`

## Range partition test

For enum types with documented range partitions in doc
comments (e.g., "1-31 internal, 32-127 standard, 128-255
custom"), the generator also emits a test verifying every
named constant falls within its documented range.

## Why

Enum types are a common source of silent bugs:

- A new constant is added but has no test coverage.
- The stringer directive is not regenerated after adding a
  constant, so the new value prints as `Status(4)` in logs.
- A constant is assigned a value outside its documented
  range partition.
- JSON/codec round-trip breaks silently.

The generated tests catch all of these at `go generate`
time.

## Scale

~30 enum types x ~40 lines = ~1,200 lines.
