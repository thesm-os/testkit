# Recording Wrappers

Reads a Go interface definition, emits a recording
decorator that wraps any implementation and captures every
method call for assertion. Independent of stubs — can
wrap in-memory impls, production impls, or any other
implementation of the interface.

## go:generate directive

```go
//go:generate testkit recording -o storetest/recording_store.gen.go Store
//go:generate testkit recording -o storetest/recording_projection.gen.go Projection

// Multiple into one file:
//go:generate testkit recording -o storetest/recording_wrappers.gen.go Publisher Compiler
```

## Default output

`<package>test/recording_<subject>.gen.go`

## What is generated

Given an interface `Store` with methods `Put(ctx, item)
error` and `Get(ctx, id) (string, error)`:

```go
// Code generated by testkit recording. DO NOT EDIT.

package storetest

import (
    "context"

    "go.thesmos.sh/testkit"
    "example.com/myapp/store"
)

// Compile-time interface check.
var _ store.Store = (*RecordingStore)(nil)

// StorePutCall captures the arguments to a single
// Put invocation.
type StorePutCall struct {
    Ctx context.Context
    Req store.PutRequest
}

// StoreGetCall captures a Get invocation.
type StoreGetCall struct {
    Ctx context.Context
    ID  string
}

// RecordingStore wraps a store.Store and records
// every method call. The inner implementation handles
// the actual logic; the recorder observes.
type RecordingStore struct {
    inner store.Store
    Puts  *testkit.Recorder[StorePutCall]
    Gets  *testkit.Recorder[StoreGetCall]
    // ... one recorder per method
}

// NewRecordingStore wraps inner with call recording.
func NewRecordingStore(inner store.Store) *RecordingStore {
    return &RecordingStore{
        inner: inner,
        Puts:  testkit.NewRecorder[StorePutCall](),
        Gets:  testkit.NewRecorder[StoreGetCall](),
    }
}

func (r *RecordingStore) Put(ctx context.Context, req store.PutRequest) error {
    r.Puts.Record(StorePutCall{Ctx: ctx, Req: req})
    return r.inner.Put(ctx, req)
}

func (r *RecordingStore) Get(ctx context.Context, id string) (string, error) {
    r.Gets.Record(StoreGetCall{Ctx: ctx, ID: id})
    return r.inner.Get(ctx, id)
}

// ... one method per interface method

// --- Assertion helpers ---

// AssertPutCalledOnce fails unless exactly one Put
// was recorded; returns the call for further assertion.
func (r *RecordingStore) AssertPutCalledOnce(t testing.TB, msg string) StorePutCall {
    t.Helper()
    return r.Puts.AssertCalledOnce(t, msg)
}

// AssertPutCalledN fails unless exactly n Puts were
// recorded; returns all calls.
func (r *RecordingStore) AssertPutCalledN(t testing.TB, n int, msg string) []StorePutCall {
    t.Helper()
    return r.Puts.AssertCalledN(t, n, msg)
}

// AssertPutNotCalled fails if any Put was recorded.
func (r *RecordingStore) AssertPutNotCalled(t testing.TB, msg string) {
    t.Helper()
    r.Puts.AssertNotCalled(t, msg)
}

// ... one Assert*CalledOnce + Assert*CalledN + Assert*NotCalled per method
```

## Usage

Recording wrappers are composable with any implementation:

```go
// Wrap an in-memory impl to verify call patterns:
rec := storetest.NewRecordingStore(
    storetest.NewInMemoryStore(),
)
_ = rec.Put(ctx, item)

// Concise assertion — one line instead of three:
call := rec.AssertPutCalledOnce(t, "single put")
testkit.Equal(t, call.Req.ID, expectedID, "id")

// Wrap a production impl in integration tests:
rec := storetest.NewRecordingStore(
    postgres.NewStore(pool),
)
```

## Advanced usage with Recorder primitives

Recording wrappers expose `testkit.Recorder[T]` fields
directly, giving access to the full Recorder API —
filtering, waiting, hooks, and gating:

```go
// Filter: find all Puts with a specific ID:
matching := rec.Puts.Filter(func(c storetest.StorePutCall) bool {
    return c.Req.ID == "target-id"
})

// Wait: block until 3 Puts arrive (async integration test):
rec.Puts.WaitForN(t, 3, 5*time.Second)

// Hook: wire observation into sim trace:
rec.Puts.OnRecord(func(c storetest.StorePutCall) {
    trace.Append(tick, Event{Kind: "put", ID: c.Req.ID})
})

// Gate: control when a Put completes (race condition test):
gate := rec.Puts.NewGate()
go func() { _ = s.Put(ctx, item) }() // blocks
// ... do something that should happen while Put is blocked ...
gate.Release()
```

## Why

Recording is independent from stubbing. Some packages
need recording without a stub (wrapping the real
implementation to observe calls in integration tests).
Others need a stub without recording (the in-memory impl
is sufficient). Making them separate generators means
each `//go:generate` directive does one thing.

The rich Recorder API (filtering, waiting, hooks, gating)
makes recording wrappers the primary observation layer
for simulation and integration tests — not just a call
counter.

## Generated tests

For every recording wrapper, a companion test file is
generated (e.g., `recording_store.gen_test.go`). These
tests verify every method records correctly and delegates
to the inner implementation.

```go
// Code generated by testkit recording. DO NOT EDIT.

package storetest_test

import (
    "testing"

    "go.thesmos.sh/testkit"
    "example.com/myapp/store/storetest"
)

func TestRecordingStore_Put_Records(t *testing.T) {
    t.Parallel()

    innerCalled := false
    inner := storetest.NewStoreStub(
        func(ctx context.Context, req store.PutRequest) error {
            innerCalled = true
            return nil
        },
        func(ctx context.Context, id string) (string, error) { return "", nil },
    )

    rec := storetest.NewRecordingStore(inner)
    ctx := t.Context()
    req := store.PutRequest{}

    err := rec.Put(ctx, req)
    testkit.NoError(t, err, "Put must succeed")
    testkit.True(t, innerCalled, "inner must be called")
    testkit.Equal(t, rec.Puts.CallCount(), 1, "one call recorded")

    call := rec.Puts.LastCall()
    testkit.Equal(t, call.Ctx, ctx, "context must be captured")
    testkit.Equal(t, call.Req, req, "request must be captured")
}

func TestRecordingStore_Get_Records(t *testing.T) {
    t.Parallel()

    inner := storetest.NewStoreStub(
        func(context.Context, store.PutRequest) error { return nil },
        func(context.Context, string) (string, error) { return "found", nil },
    )

    rec := storetest.NewRecordingStore(inner)

    val, err := rec.Get(t.Context(), "key-1")
    testkit.NoError(t, err, "Get must succeed")
    testkit.Equal(t, val, "found", "must return inner result")
    testkit.Equal(t, rec.Gets.CallCount(), 1, "one call recorded")
}

func TestRecordingStore_Reset(t *testing.T) {
    t.Parallel()

    inner := storetest.NewStoreStub(
        func(context.Context, store.PutRequest) error { return nil },
        func(context.Context, string) (string, error) { return "", nil },
    )

    rec := storetest.NewRecordingStore(inner)
    _ = rec.Put(t.Context(), store.PutRequest{})
    testkit.Equal(t, rec.Puts.CallCount(), 1, "pre-reset")

    rec.Puts.Reset()
    testkit.Equal(t, rec.Puts.CallCount(), 0, "post-reset")
}

// ... one Records + Reset test per interface method
```

Coverage target: 100% of the generated recording code.

## Scale

~15 recording wrappers x ~60 lines = ~900 lines generated.
~15 companion test files x ~50 lines = ~750 lines generated.
