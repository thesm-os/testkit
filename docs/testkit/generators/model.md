# State Machine Models

Reads a Go interface definition, emits a
`rapid.StateMachine` model with generated commands and an
oracle interface. The model drives property-based testing
by calling both the real implementation and a pure
in-memory reference, comparing results on every step.

## go:generate directive

```go
//go:generate testkit model -o storetest/store_model.gen.go Store
//go:generate testkit model -o storetest/cache_model.gen.go Cache
```

## Default output

`<package>test/<subject>_model.gen.go`

## What is generated

Given an interface `Store` with methods `Put`,
`List`, `Get`, `Delete`:

```go
// Code generated by testkit model. DO NOT EDIT.

package storetest

import (
    "context"

    "pgregory.net/rapid"

    "example.com/myapp/store"
)

// StoreOracle defines the expected behaviour for each
// Store method. The caller implements this as a pure
// in-memory reference model — no I/O, no concurrency,
// just correct logic.
type StoreOracle interface {
    Put(req store.PutRequest) error
    List(opts store.ListOptions) ([]store.Item, error)
    Get(id string) (string, error)
    Delete(req store.DeleteRequest) error
}

// StoreModel pairs a real Store with an oracle for
// property-based testing. Each command calls both, compares
// results, and fails the rapid test on divergence.
type StoreModel struct {
    Real   store.Store
    Oracle StoreOracle
    Ctx    context.Context
    Hints  StoreDrawHints
}

// PutCommand generates a random Put request, calls
// both real and oracle, asserts matching results.
func (m *StoreModel) PutCommand(t *rapid.T) {
    req := m.drawPutRequest(t)
    expected := m.Oracle.Put(req)
    actual := m.Real.Put(m.Ctx, req)
    assertEqualError(t, expected, actual, "Put")
}

// GetCommand calls Get on both, asserts matching results.
func (m *StoreModel) GetCommand(t *rapid.T) {
    id := m.drawID(t)
    expectedVal, expectedErr := m.Oracle.Get(id)
    actualVal, actualErr := m.Real.Get(m.Ctx, id)
    assertEqualError(t, expectedErr, actualErr, "Get error")
    if expectedErr == nil {
        assertEqual(t, expectedVal, actualVal, "Get value")
    }
}

// ... one *Command per interface method

// drawPutRequest generates a random PutRequest.
// If Hints.PutRequest is set, delegates to it; otherwise
// uses default rapid generators.
func (m *StoreModel) drawPutRequest(t *rapid.T) store.PutRequest {
    if m.Hints.PutRequest != nil {
        return m.Hints.PutRequest(m.Oracle, t)
    }
    return store.PutRequest{
        ID:   rapid.String().Draw(t, "id"),
        Data: []byte(rapid.String().Draw(t, "data")),
        // ... default random generation per field
    }
}

// StoreDrawHints allows domain-specific input constraints.
// Set a field to override the default random generator for
// that command. Nil means use the generated default.
type StoreDrawHints struct {
    PutRequest  func(oracle StoreOracle, t *rapid.T) store.PutRequest
    ListOptions func(oracle StoreOracle, t *rapid.T) store.ListOptions
    // ... one per command
}

func assertEqualError(t *rapid.T, expected, actual error, method string) {
    // errors.Is comparison with clear failure message
}

func assertEqual[T comparable](t *rapid.T, expected, actual T, field string) {
    // == comparison with clear failure message
}
```

## Injection point

The developer implements the oracle — a pure in-memory
reference that defines correct behaviour without I/O:

```go
// storetest/store_model_oracle.go — hand-written

type mapOracle struct {
    items map[string]store.Item
}

func (o *mapOracle) Put(req store.PutRequest) error {
    if _, ok := o.items[req.ID]; ok {
        return store.ErrConflict
    }
    o.items[req.ID] = store.Item{
        ID:   req.ID,
        Data: req.Data,
    }
    return nil
}

func (o *mapOracle) Get(id string) (string, error) {
    item, ok := o.items[id]
    if !ok {
        return "", store.ErrNotFound
    }
    return item.Data, nil
}
```

Tests wire the model:

```go
func TestStore_Model(t *testing.T) {
    rapid.Check(t, func(t *rapid.T) {
        impl := storetest.NewInMemoryStore()
        oracle := &mapOracle{items: make(map[string]store.Item)}
        model := &storetest.StoreModel{
            Real:   impl,
            Oracle: oracle,
            Ctx:    t.Context(),
        }
        t.Repeat(map[string]func(*rapid.T){
            "Put":    model.PutCommand,
            "Get":    model.GetCommand,
            "List":   model.ListCommand,
            "Delete": model.DeleteCommand,
        })
    })
}
```

## What is NOT generated

- The oracle implementation (domain logic)
- Draw hint implementations (domain constraints)

## Why

Property-based state machine testing finds bugs that
hand-written tests miss — it explores arbitrary
interleaving of operations with random inputs. The
generated model eliminates the boilerplate of wiring
commands, drawing inputs, and comparing results. The
developer focuses on the one hard part: what is correct
behaviour?

## Scale

~40 interfaces x ~200 lines = ~8,000 lines.
