# Differential Test Harness

Reads an interface + N implementation paths, emits a
fan-out wrapper that calls all implementations and compares
results pairwise.

## go:generate directive

```go
// In the sim/simtest package that owns the differential tests:
//go:generate testkit differential -o differential_store.gen.go store.Store
```

The implementation list is not encoded in the directive —
the caller constructs the `Differential*` struct with
real implementations at test time (see injection point
below).

## Default output

`differential_<name>.gen.go`

## What is generated

Given an interface `Store` with three implementations:

```go
// Code generated by testkit differential. DO NOT EDIT.

package simtest

import (
    "context"
    "testing"

    "go.thesmos.sh/testkit"
    "example.com/myapp/store"
)

// DifferentialStore wraps N store.Store implementations
// and calls all of them on every operation, asserting
// identical results. Divergence between any two
// implementations fails the test.
type DifferentialStore struct {
    t     testing.TB
    impls []store.Store
    names []string
}

func NewDifferentialStore(
    t testing.TB,
    impls []store.Store,
    names []string,
) *DifferentialStore {
    return &DifferentialStore{t: t, impls: impls, names: names}
}

func (d *DifferentialStore) Put(ctx context.Context, req store.PutRequest) error {
    errs := make([]error, len(d.impls))
    for i, impl := range d.impls {
        errs[i] = impl.Put(ctx, req)
    }
    d.assertAllEqualErrors(errs, "Put")
    return errs[0]
}

func (d *DifferentialStore) Get(ctx context.Context, key string) (string, error) {
    type result struct {
        val string
        err error
    }
    results := make([]result, len(d.impls))
    for i, impl := range d.impls {
        results[i].val, results[i].err = impl.Get(ctx, key)
    }
    d.assertAllEqualErrors(
        mapSlice(results, func(r result) error { return r.err }),
        "Get",
    )
    if results[0].err == nil {
        for i := 1; i < len(results); i++ {
            testkit.Equal(d.t, results[i].val, results[0].val,
                d.names[i]+" Get value diverged from "+d.names[0])
        }
    }
    return results[0].val, results[0].err
}

// ... one fan-out method per interface method

func (d *DifferentialStore) assertAllEqualErrors(errs []error, method string) {
    d.t.Helper()
    for i := 1; i < len(errs); i++ {
        if (errs[0] == nil) != (errs[i] == nil) {
            d.t.Fatalf("%s: %s returned %v but %s returned %v",
                method, d.names[0], errs[0], d.names[i], errs[i])
        }
    }
}
```

## Injection point

The caller constructs with real implementations:

```go
func TestStore_Differential(t *testing.T) {
    inMem := storetest.NewInMemoryStore()
    pg := postgres.NewStore(pool)
    sl := sqlite.NewStore(db)

    diff := simtest.NewDifferentialStore(t,
        []store.Store{inMem, pg, sl},
        []string{"inmemory", "postgres", "sqlite"},
    )

    // Drive diff through the same test workload — any
    // divergence between implementations fails immediately.
    diff.Put(ctx, req)
    val, err := diff.Get(ctx, key)
    // ...
}
```

## Why

Differential testing catches implementation-specific bugs
that conformance suites miss. A conformance suite tests
one implementation in isolation; a differential harness
tests N implementations against each other, exposing
semantic differences in edge cases (e.g., Postgres sorts
NULLs differently than SQLite).

## Scale

~5 interfaces x ~200 lines = ~1,000 lines.
